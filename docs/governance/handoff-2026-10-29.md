## 2. 本轮已完成

### 2.1 误报控制

- **CON-004**：版式豁免改为精确匹配 + 封面专用短语；不再用 `"Title"` 子串豁免 `Title and Content`；结论关键词只扫非标题正文；演讲者备注不再单独作为结论。
- **对齐检查**：标题/正文不再互比；同排比较 top，同列比较宽度/右边界；嵌套/覆盖文本框跳过。
- **TERM-003**：仅匹配全大写技术缩写；支持 `排除白名单` + `仅首次出现`；定义后复用不再报。
- **CON-003**：接入 `vocab/accept.txt`，领域缩写白名单不报未定义。
- **CON-001**：年份/季度/工艺节点作为限定词保留，且不参与指标值比较。

### 2.2 格式/版面

- **继承格式**：PPTX 解析 theme/master/layout/txStyles；DOCX 解析 style/based-on/docDefaults；模型增加 `effective_font_*` / `font_size_inherited`。
- **格式作用域**：FMT-001/002/003/005 收敛为 PPTX；DOCX 的 16pt 标题、300 字页、宋体不再误报。
- **Group 坐标**：按 `off/ext/chOff/chExt` 递归变换为绝对坐标。
- **真实项目符号**：提取 `a:buChar` / `a:buAutoNum`；FMT-007 与 AutoFixer 使用真实类型。
- **新增内置检查**：
  - `FMT-OVERLAP` 元素重叠（25% 阈值，排除嵌套/空占位/全屏背景）
  - `FMT-SAFE-MARGIN` 安全边距（1%）
  - `FMT-TEXT-OVERFLOW` 文本溢出估算（非渲染级）
  - `FMT-FOOTER` 页脚/页码/日期部分缺失
  - `FMT-IMAGE` 图片宽高比/DPI/alt text
  - `FMT-CHART` 图表缺标题
  - `STR-MASTER` 多母版检测
- **默认字号上限**：FMT-002 调整为 **标题 28-44pt / 正文 12-32pt**（对齐 Office 默认主题）。

### 2.3 文字规范

- 新增 `PUNCT-001~007`：重复/冲突标点、中英标点混用、全半角、括号配对、省略号/破折号。
- 新增 `TXT-REDUNDANT`：高精度中文冗余表达。
- 中文基础模式改为始终执行，不再只存在于 LanguageTool Tier-3。
- 移除 `general_tech.yaml` 中与 FMT-MIXED/PUNCT 重复的规则。
- 检查前掩码 URL/邮箱/行内代码/围栏代码。

### 2.4 UI/工作流/修复

- 干净文档 `findings=[]` 也显示 0 问题摘要与报告下载。
- 稳定豁免键 `exemption_key`（dedup_key + message + location）。
- 批量页面豁免按 `(文件, 页码)`；批量 finding 写入 `metadata["source_file"]`。
- 无效正则转 `SYS-ERROR`；doctor 可选依赖缺失不再 exit 1。
- 旧版 `.ppt`/`.doc` 给出“另存为 .pptx/.docx”提示。
- AutoFixer 支持 Group/表格/页眉页脚；跳过 `+mj-lt`/`+mn-lt` 主题字体；真实 `a:buChar` 走 XML。
- HTML 报告按 severity → 页码 → rule_id 排序。
